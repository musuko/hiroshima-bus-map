
作業手順（これだけ見ればOK）

PowerShellを開き、d:\users\downloads\current_data に移動した状態からスタートします。

1. 全会社の最新データを一括ダウンロード＆解凍する

GitHub上に作ったあの便利なPythonプログラムを実行します。
powershell
python download_and_extract.py
コードは注意してご使用ください。
（※画面上で全会社のダウンロードと上書き解凍が自動で進みます）

2. 新しくなったファイルをGitにすべて登録する

powershell
git add .
コードは注意してご使用ください。
powershell
git commit -m "運行データを最新に更新"
コードは注意してご使用ください。
（※ " " の中のコメントは「10月データ更新」など、その日の日付に変えても大丈夫です）

3. GitHubへ一括アップロードする

powershell
git push origin main
コードは注意してご使用ください。

💡 もし最後にエラー（rejected）が出た場合の対策

別日までの間に、もしブラウザ（GitHubの画面）側でファイルを直接触ったり、他のPCから書き換えたりして「歴史のズレ」が起きて送信が拒否された場合は、いつもの強制送信コマンドを打てば一発で解決します。
powershell
git push -f origin main
コードは注意してご使用ください。
次回からは、この「1. プログラム実行 ➔ 2. add & commit ➔ 3. push」の3ステップだけで、何社分あろうと一瞬で作業が終了します。
