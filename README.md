## 本日の広島県のバス時刻表を調べることができます。
### 使い方
- https://musuko.github.io/hiroshima-bus-map/
- バス会社を選択
- 使いたいバス停を地図で選択すると、そのバス停の時刻表が開く
### バス会社
- 広電バス
- 広島バス
- 広島交通
- 芸陽バス
- 備北バス
- JRバス
- ボンバス
- フォーブル
- おおのハートバス
- 呉生活バス
- 廿日市自主運行バス
- 朝日バス
- 尾道バス
### 他機能
- 地図にバスの現在地が表示される
- 表示されたバスを選択すると、そのバスの目的地や時刻表が表示される。
### 課題
- 元データが更新されたとき、自動で時刻表に反映させる
- 他の日付の時刻表を表示する
